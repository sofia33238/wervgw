TTAds Hub 1.0.0 — расширение Chrome для TikTok Ads Manager
==========================================================

Manual-кампании · массовые апелляции · S2S-постбэки · быстрые пиксели — в одном окне.

УСТАНОВКА
1. Откройте chrome://extensions (в антидетект-браузере — страницу расширений профиля).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите ЭТУ папку (где лежит manifest.json).
4. Закрепите расширение на панели браузера.
5. Старые Plusone / MNL Control / Appeal Desk отключите: они делают то же самое.
После обновления расширения перезагрузите вкладку TikTok Ads Manager (F5).

ИСПОЛЬЗОВАНИЕ
• Manual: «Создать» → выберите App Promotion / Lead Generation / Sales → расширение → «Включить Manual».
• Апелляции: откройте список Ad (или Ad group) → вкладка «Апелляции» → выберите строки → «Апелляция» → «Отправить».
• S2S: ссылка постбэка для Keitaro, архив серверного скрипта, тест события, быстрое создание пикселя.
• Журнал: все действия расширения; настройки — значок ⚙ в шапке.

Подробности, список улучшений и ограничения — в README.md репозитория.
Расширение работает только на ads.tiktok.com и business-api.tiktok.com, данные хранит локально.
